FFmpeg binary provenance
========================

Bundled version: FFmpeg 8.1.2 essentials_build
Build distributor: Gyan Doshi / gyan.dev
Upstream project: https://ffmpeg.org/
Binary source page: https://www.gyan.dev/ffmpeg/builds/
Release asset used:
  https://github.com/GyanD/codexffmpeg/releases/download/8.1.2/ffmpeg-8.1.2-essentials_build.zip
Build configuration: GPL enabled, version 3 enabled, static Windows build.

The binaries are NOT committed to this repository. They are fetched by
tools_fetch_ffmpeg.py, which the release workflow runs before building and which
a developer runs once after cloning. That file is the single place the version
and the download URL are declared; change it there and nowhere else.

Why the essentials build rather than the full build
---------------------------------------------------
The application invokes exactly three things: ffprobe for stream metadata, the
native AAC encoder for its compact upload copy and its per-turn range cuts, and
the MP4/M4A muxer. The essentials build carries all of them. The full build adds
external libraries this application never calls, at 268 MB of extra download.

Verified against the essentials build before the switch: probing of .wav, .m4a,
.mp3, .flac, .webm, .mp4 and .aac; compress_command (AAC mono 16 kHz 32 kbps);
range_command in both re-encode and stream-copy modes; and chunk creation.

corresponding-source obligations for the exact build they publish. If either
executable is replaced, update this provenance file and tools_fetch_ffmpeg.py at
the same time. Do not assume a different FFmpeg build has identical terms.
